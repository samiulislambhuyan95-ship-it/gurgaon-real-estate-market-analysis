# Gurgaon Real Estate Market Analysis

A Python-based data analysis project focused on exploring the Gurgaon real estate market using property-level data.

## Project Overview

This project analyzes real estate data from Gurgaon using Python and explores relationships between property area and price per square foot.

The analysis includes data processing, categorization of property areas, calculation of average rates per square foot, and visualization of market patterns.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed

The project includes:

- Data loading and exploration using Pandas
- Data cleaning and preparation
- Categorization of properties based on area
- Calculation of average rate per square foot
- Analysis of property area and pricing patterns
- Data visualization using Matplotlib and Seaborn

## Key Analysis

### Average Rate per Sqft by Property Area

The project calculates the average rate per square foot for different property-area categories:

| Area Category | Average Rate per Sqft |
|---|---:|
| Below 1000 | 11,446.29 |
| 1000–2000 | 14,580.83 |
| 2000–3000 | 16,117.32 |
| 3000–5000 | 16,284.56 |
| Above 5000 | 19,239.28 |

The analysis shows how the average rate per square foot varies across different property-area categories.
